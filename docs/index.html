Variable Font Optical Sizing Axis Compiler (opsz)

      

        Minecraft FreeType pins all variation axes to default coordinates. For variable fonts declaring an opsz axis, rendering at GUI sizes with default optical sizing produces distorted stroke contrast. This compiler calculates exact clamped and normalized axis coordinates across Minecraft UI contexts.

Unicode 16.0 Plane Coverage & Surrogate Safety Validator

      

        Validates codepoint coverage across all 17 Unicode planes (BMP, SMP, SIP, TIP, SSP, Plane 15/16 PUAs) and audits lone/unpaired UTF-16 surrogates (U+D800..U+DFFF) that crash JVM String encoders and corrupt chat rendering.
